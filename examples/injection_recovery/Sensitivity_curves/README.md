# Theory files for injection-recovery

Place here the files needed by the injection-recovery example.

Expected structure:

```text
theory/
├── Zed_abs.txt
├── Zed_phase.txt
└── Sensitivity_curves/
    └── aligo_O4high.txt
```

`Zed_abs.txt` and `Zed_phase.txt` are the greybody-factor grids for the (22) multipole available at https://zenodo.org/records/19811974.

`Sensitivity_curves/aligo_O4high.txt` is the PSD input used by the zero-noise injection setup.
