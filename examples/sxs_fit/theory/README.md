# Theory files for the SXS fit example

Place here the files needed by the SXS fitting example.

Expected structure:

```text
examples/sxs_fit/theory/
├── dataAbs22.txt
├── dataPhase22.txt
├── l2
├── l3
└── l4
```

Here the files are set for the l=2,m=2 multipole. For different (l,m) modes you have to add in this folder the corresponding absolute value of the reflection amplitude (dataAbslm.txt) and phase (dataPhase22.txt). 
(CHECKK NEGATIVE M)
